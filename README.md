# ⋆౨ৎ˚⟡˖ ࣪🐼 Panda Login Form

Este projeto é um formulário de login divertido e interativo com um panda animado que reage aos campos de entrada! 🐾

![Panda Login Preview](img/screenshot1panda.png)

## ⊹₊ ⋆✨ Funcionalidades

- 👁️ O panda move os olhos ao focar no campo de **usuário**
- 🙈 O panda cobre os olhos ao focar no campo de **senha**
- 💫 Animações suaves com CSS
- 📱 Design responsivo para dispositivos móveis

## ₊ ⊹🪻 ✧˚🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript (puro)
